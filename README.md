# 🌌 Anoushka Saha — Portfolio Website

A modern, responsive developer portfolio built with a dark aesthetic and smooth animations to showcase my projects, skills, and experience.

🔗 Live Website: https://sanoushka.github.io/

---

## ✨ Features

- 🌌 Animated starfield background
- 🎯 Clean and minimal UI with neon accents
- 📱 Fully responsive design
- 🧠 Structured sections (About, Skills, Projects, Certifications, Contact)
- ⚡ Smooth scroll and reveal animations
- 🔗 Integrated GitHub, LinkedIn, and Resume links

---

## 🛠️ Tech Stack

- HTML5  
- CSS3 (Custom styling + animations)  
- JavaScript (Vanilla JS)  

---

## 📂 Sections Included

- **Hero Section** — Introduction and quick navigation  
- **About Me** — Profile and background  
- **Skills** — Technical stack and tools  
- **Projects** — Featured work  
- **Certifications** — Courses and achievements  
- **Achievements** — Extracurriculars and milestones  
- **Contact** — Links and communication
